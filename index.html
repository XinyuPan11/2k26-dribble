给 200 小时老玩家的版本：跳过基础，只讲手柄的底层逻辑 + 能直接练的连招。每个连招都有“输入回放”动画，代替看视频。

① 第一性原理：所有运球 = 4 个变量的组合

招式 = 右摇杆 方向 × 拨 / 按住 / 速度 × RT 加速键 有无 × 左摇杆 冲出方向

右摇杆 选“哪个动作”

方向一律相对持球手：往持球手那边 = 不换手（迟疑），往非持球手那边 = 换手（交叉）。往下 = 后撤，往上 = 向前试探。

拨 vs 按住 vs 快慢

轻拨回中 = 单个动作；按住 = 更长的版本（逃脱/上篮类）。2K26 新增：拨得快动作就快，拨得慢动作就慢——这就是“节奏”的来源。

RT 把动作变“爆发版”

同一个右摇杆方向，加不加加速键是两个不同的招：↓ 是后撤步，RT+↓ 是急停拉回（snatchback）。任何右摇杆动作之后按住加速 + 推左摇杆 = 爆发（burst）。

左摇杆 决定“冲向哪”

右摇杆只负责动作，真正过人的是动作结束那一瞬间左摇杆指向的方向（launch angle）。很多人连招不出效果，是左摇杆还指着防守人。另：LT 轻按护球、按住减速。
一句话心法：右摇杆“骗”，左摇杆+加速“走”。连招 = 骗（一次或两次）→ 看防守重心 → 走。
2K26 官方说明：运球输入更快、更容易被“打断/接续”，所以连招的关键是在上一个动作球落地前输入下一个，而不是等动画放完。

不按加速：轻拨回中

按住 RT 加速：爆发 / 逃脱版

③ 连招慢动作手柄回放

选一个连招 → 默认 0.25 倍慢放。摇杆后面的拖尾 = 刚刚走过的路径；扳机变红/绿 = 正在按住。用「下一步」可以一步一步看。键盘：空格 播放/暂停，← → 上一步/下一步。

    ④ 练习方法（最高效路径）

    1. 先单练“二段误导”

    它是 2K26 区分高手的输入：第一下不按加速，第二下按住加速且在球第一次落地前输入。在自由训练里只练这一个，直到不看手也能出。

    2. 每个动作都练“左摇杆收尾”

    同一个招，分别往 ↖ / ↑ / ↗ 三个方向冲出去各 10 次。你会发现过人成功率主要取决于这一步。

    3. 用快慢做节奏

    同一个 size-up，故意一次拨慢一次拨快。防守 AI 和真人都是对节奏反应，而不是对招式名。

    4. 检查动画和属性

    能不能出某个招很大程度取决于运球属性和你装的招牌动作包（size-up / escape / combo 包）。招不灵先查动画门槛，再怀疑手法。
